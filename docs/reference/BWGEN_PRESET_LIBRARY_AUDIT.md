# BWGen Preset Library Audit

## Why the library matters

The BWGen community library is useful as a **composition and feature-behavior corpus**. It demonstrates how real users combine multiple voices, segments, repetitions, frequency ramps, noise, background WAV files, modulation, and long sessions.

It is **not** a scientific truth database. The library openly includes categories and descriptions involving treatment/healing, subliminal programming, chakras, out-of-body experiences, astral projection, and experimental/weird uses. Individual historic presets make specific claims about neurotransmitters, cognition, metaphysical effects, and medical outcomes that should not be inherited as factual metadata.

## Import policy

When importing legacy metadata:

- Preserve title, author, category, dates, source URL where available, and original description as **Legacy author text**.
- Add our own evidence state separately.
- Never transform a legacy claim into an app-generated fact.
- Identify missing background files and unresolved parameters in an import report.
- Preserve actual segment/voice values exactly when parser confidence is sufficient.
- Never silently substitute “equivalent” modern parameters when exact legacy semantics are unknown.

## Community-system upgrades

Our library should include ratings/reviews, favorites, downloads, forks/remixes, version lineage, compatibility status, moderation/reporting, asset-license status, evidence label, verified research citation when applicable, and exact engine/schema version.

## Composition patterns worth carrying forward

- multi-segment ramping rather than one fixed frequency
- repeated segment blocks
- simultaneous voices at different carrier/difference pairs
- noise plus tone layers
- background sound interval/trigger behavior
- modulation of noise/background
- long gradual fades and transitions
- external recorded spoken/audio tracks

## Naming/claim redesign

Historic categories may appear under a “Legacy BWGen” filter to preserve provenance, but the primary modern taxonomy should be signal- and use-oriented: Relaxation design, Focus design, Sleep design, Meditation design, Research protocol, Soundscape, Experimental audio, Community, and Legacy. Evidence badges are orthogonal to categories.
