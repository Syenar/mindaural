# Reference / Bundled Asset Policy

Do not copy BWGen bundled sounds, artwork, commercial AudioStrobe content, or third-party preset assets.

The first-wave bundled soundscape library contains **at least 24 production-ready sounds** and every sound is either project-created/procedural or individually verified **CC0**. No attribution-required, unknown-license, or ambiguous third-party audio is used in the default bundle.

For every third-party CC0 asset store source URL, creator/uploader, original filename, retrieval date, explicit CC0 statement/license snapshot, source SHA-256, and any transformed output SHA-256 under `assets/licenses/`.
